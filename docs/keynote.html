The problem

Acceptance is one boundary

SDK buffers, queue admission, retry limits, collector crashes, and backend indexing each affect delivery. A success response upstream does not establish an end-to-end result.

WorkloadGateway → scheduler → worker. Traces, logs, and metrics.

Evidence model

A controlled failure, a measured result

Each experiment stores its hypothesis, signal identities, queue observations, backend queries, and assertions. A fresh recovery canary distinguishes backend health from recovery of the original backlog.

Recorded observations

Persistent storage has limits

The recorded persistent crash recovered 12/12 traces and 12/12 logs. Memory-only crash and retry exhaustion recovered 0/12 originals of each signal; new canaries arrived. Saturation recovered the 4/12 signals admitted per queue.

Design considerations

Scaling requires more than queue size

Measure ingress, backlog bytes, export capacity, delivery delay, and disk behavior. Separate failure domains. Add durable job ownership, authenticated access, and durable signal backends for shared operation.

Siva Babu · Telemetry Reliability LabBack07 / 08Next
Scope

Inspectable infrastructure engineering

The repository includes Python source, configuration, tests, and recorded evidence. Synthetic CPU work and bounded failures establish specific behavior; they do not establish GPU performance, production adoption, or exactly-once delivery.
